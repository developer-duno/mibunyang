# 수동 테스트 체크리스트 (QA)

> 자동 테스트로 커버하기 어려운 UI/UX 시나리오를 수동으로 검증합니다.

## 1. 메인 흐름 (정상)

- [ ] 1-1. 첫 로딩 시 아파트 목록이 표시된다
- [ ] 1-2. 프로필(실거주/투자/신혼 등) 전환 시 점수 순위가 변경된다
- [ ] 1-3. 지역 필터(시도) 선택 시 해당 지역만 표시된다
- [ ] 1-4. 구/군 필터 선택 시 해당 구만 표시된다
- [ ] 1-5. 예산 범위(min/max) 슬라이더 조작 시 필터링된다
- [ ] 1-6. 검색어 입력 시 debounce 후 결과가 필터링된다
- [ ] 1-7. 정렬(점수순/가격순/미분양률순) 전환이 동작한다
- [ ] 1-8. 더보기 버튼 클릭 시 추가 아파트가 로드된다
- [ ] 1-9. 아파트 카드 클릭 시 상세 모달이 열린다
- [ ] 1-10. 상세 모달에서 6개 카테고리 점수가 표시된다
- [ ] 1-11. 비교함에 아파트 2개 이상 추가 후 비교 화면이 열린다
- [ ] 1-12. 비교 화면에서 레이더 차트가 정상 렌더링된다
- [ ] 1-13. 비교함에서 아파트 제거가 동작한다
- [ ] 1-14. 커스텀 가중치 슬라이더 조작 시 합계가 100%를 유지한다
- [ ] 1-15. 시세 바 차트가 분양가 대비 주변 시세를 표시한다

## 2. 메인 흐름 (예외)

- [ ] 2-1. API 응답 지연(3초+) 시 로딩 스피너가 표시된다
- [ ] 2-2. 필터 결과가 0건일 때 "결과 없음" 메시지가 표시된다
- [ ] 2-3. 네트워크 오프라인 시 에러 메시지가 표시된다

## 3. 상담 기능

- [ ] 3-1. 상담 신청 버튼 클릭 시 폼이 열린다
- [ ] 3-2. 필수 항목 미입력 시 유효성 검증 메시지가 표시된다
- [ ] 3-3. 상담 신청 완료 시 확인 토스트가 표시된다

## 4. 전문가 로그인

- [ ] 4-1. 전문가 탭에서 로그인 폼이 표시된다
- [ ] 4-2. 올바른 인증 정보로 로그인 성공 시 전문가 페이지가 표시된다
- [ ] 4-3. 로그아웃 시 일반 목록 탭으로 복귀한다

## 5. 반응형 (모바일/PC)

- [ ] 5-1. PC(1200px+): 카드 그리드가 3열로 표시된다
- [ ] 5-2. 태블릿(768px~1199px): 카드 그리드가 2열로 표시된다
- [ ] 5-3. 모바일(~767px): 카드가 1열 풀폭으로 표시된다
- [ ] 5-4. 모바일에서 상세 모달이 전체화면으로 표시된다
- [ ] 5-5. 모바일에서 필터 패널이 접힘/펼침 토글된다
- [ ] 5-6. PC에서 비교 화면이 나란히 배치된다
