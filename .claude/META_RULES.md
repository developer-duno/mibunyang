# CLAUDE.md 유지 규칙 (비대화 방지)

> CLAUDE.md 본문 편집 전 이 파일을 먼저 참조.

CLAUDE.md는 매 세션 시스템 프롬프트로 자동 로드된다. **한 번 추가한 줄이 1,000번 컨텍스트로 읽힌다**고 간주하고 보수적으로 작성.

## 절대 추가 금지

- ❌ 세션별 상세 작업 내역 → `.claude/SESSION_LOG.md`
- ❌ 특정 커밋 해시 (예외: 영구 규칙 박제 근거 1~2건만)
- ❌ "사건 기록" 길게 풀어 쓴 내러티브 → 한 줄 + SESSION_LOG 링크
- ❌ DB 품질 측정값·테스트 수·번들 KB → `.claude/DB_QUALITY.md` / SESSION_LOG
- ❌ 다음 세션 우선순위 → `.claude/NEXT_SESSION.md`
- ❌ 백로그 미션 진행 상태 → `.claude/BACKLOG.md`
- ❌ 환경변수 표 → `.claude/ENV_VARS.md`
- ❌ 작업 규칙 (Plan/Guard/Work/Review) → `.claude/WORK_RULES.md`
- ❌ 슬래시 커맨드/서브에이전트/hooks 메뉴 → `.claude/LOCAL_RESOURCES.md`
- ❌ 자주 쓰는 스킬 메뉴 → `.claude/SKILLS.md`

## 추가 가능 조건

다음 둘 다 만족할 때만 본문 추가:

1. **영구성**: 6개월 뒤에도 유효한 규칙·구조·전역 결정
2. **재발 방지 가치**: 같은 실수를 또 할 가능성이 충분히 높음 + **항상 로드해야 가치가 있음** (작업 시점에만 필요하면 외부 분리)

## 줄 수 가드

- **상한 150줄** — 초과 시 다음 세션 시작 시 자동 분리 작업 우선 (1차 350줄 → 2차 150줄로 강화, 2026-05-02)
- 새 섹션 추가 전 기존 섹션 통합 가능한지 먼저 검토
- "현재 진행 상황" 섹션은 **3줄 이하** (링크만)
- "교차 관심사" 같은 도메인 정보는 **하위 CLAUDE.md (`api/`, `src/components/`, `src/hooks/`, `supabase/`, `scripts/`)** 로 분산. 하위 CLAUDE.md는 해당 디렉토리에서 작업할 때만 자동 로드되니 효율적

## 분리 트리거

- CLAUDE.md 150줄 초과 → 즉시 분리 플랜
- 단일 섹션 30줄 초과 → 외부 파일 분리 검토
- "최근 N세션" 류 섹션 → 절대 본문에 두지 않음
- "작업 시점에만 필요한 정보"(환경변수, 작업 규칙 등) → 외부 분리

## 외부 분리 vs 하위 CLAUDE.md 분리 선택 기준

- **하위 CLAUDE.md 흡수**: 특정 디렉토리 작업 시 자동 로드되는 정보가 자연스러운 경우 (예: 반응형 → `src/components/CLAUDE.md`, 인증/세션 → `api/CLAUDE.md`)
- **`.claude/*.md` 외부 분리**: 작업 디렉토리에 종속적이지 않지만 항상 로드 가치는 없는 경우 (예: 환경변수, 작업 규칙)
