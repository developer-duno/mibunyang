# 카카오 전화번호 수집 + 마케팅 동의 — 설정 가이드 (사장님용)

> 세션 427에서 **코드는 이미 다 준비**됨. 이 문서는 카카오 개발자 콘솔에서 사장님이 직접 해야 하는 작업만 정리합니다.
> 코드 쪽은 손댈 게 없고, 아래 콘솔 작업 + 환경변수 1개만 켜면 전화번호가 자동으로 들어옵니다.

---

## 지금 바로 되는 것 (콘솔 작업 0, 이미 배포됨)

**마케팅 수신 동의**는 콘솔 작업 없이 바로 작동합니다.

- 카카오로 **새로** 가입하는 손님에게 로그인 직후 "마케팅 정보 수신 동의" 팝업이 뜹니다.
- 동의 / 동의 안 함 둘 다 선택 가능 (동의 안 해도 서비스는 그대로 이용).
- 선택한 결과는 서버에 저장되고, **관리자 화면 → 사용자 통계 → "마케팅·연락처"** 카드에서 동의자 수를 볼 수 있습니다.

> 이미 가입한 기존 손님에게는 다음 로그인 때 한 번 팝업이 뜹니다(아직 선택 안 한 상태라).

---

## 전화번호 수집 (카카오 비즈앱 심사 필요)

전화번호는 카카오가 **개인정보 보호** 때문에 아무 앱이나 못 받게 막아둔 항목입니다.
받으려면 카카오에 "우리는 사업자다, 이런 목적으로 전화번호가 필요하다"를 심사받아야 합니다(= **비즈앱 전환**).

### 1단계 — 카카오 개발자 콘솔에서 비즈앱 전환

1. https://developers.kakao.com 접속 → 로그인 → **내 애플리케이션** → 우리 앱 선택
2. 왼쪽 메뉴 **앱 설정 → 비즈니스** 클릭
3. **사업자 정보 등록** → 사업자등록번호 입력 (267-02-01775)
4. 심사 신청 → 보통 1~3 영업일 내 승인

### 2단계 — 전화번호 동의항목 켜기

비즈앱 승인 후:

1. 왼쪽 메뉴 **카카오 로그인 → 동의항목** 클릭
2. **전화번호** 항목 찾기 → **설정** 클릭
3. 동의 단계를 **"선택 동의"** 또는 **"필수 동의"** 로 설정
   - 추천: **선택 동의** (손님이 거부해도 로그인은 되게)
4. 수집 목적 입력 (예: "상담 연결 및 맞춤 정보 안내")
5. 저장

### 3단계 — 우리 서버에서 전화번호 받기 켜기 (환경변수 1개)

Vercel 대시보드에서 환경변수 하나만 추가하면 됩니다. (코드 수정 0)

1. Vercel → 우리 프로젝트(mibunyang) → **Settings → Environment Variables**
2. 아래 변수 추가:
   - **Key**: `VITE_KAKAO_PHONE_SCOPE`
   - **Value**: `true`
   - **Environment**: Production (체크)
3. **Save** → **Deployments** 에서 최신 배포 **Redeploy** (환경변수는 재배포해야 적용됨)

> ⚠️ **2단계(콘솔 동의항목) 전에 3단계를 켜면 카카오가 에러를 냅니다.** 반드시 콘솔 승인 → 동의항목 켜기 → 그 다음 이 환경변수를 켜세요.

### 끝

이후 카카오로 로그인하는 손님은 동의 화면에서 전화번호 제공에 동의하게 되고,
동의한 전화번호가 자동으로 우리 DB에 저장됩니다.
관리자 화면 통계의 **"전화번호 보유"** 숫자로 확인할 수 있습니다.

## 자주 묻는 것

**Q. 이미 가입한 손님의 전화번호도 받아지나요?**
A. 네. 비즈앱 켠 뒤 그 손님이 **다시 로그인**하면 그때 전화번호를 받아 채웁니다.

**Q. 손님이 전화번호 제공을 거부하면?**
A. 거부해도 로그인은 정상. 전화번호만 빈 값으로 남습니다.

**Q. 마케팅 동의는 안 받고 전화번호만 받을 수도 있나요?**
A. 둘은 독립입니다. 마케팅 동의는 이미 켜져 있고, 전화번호는 위 콘솔 작업 후 켜집니다.

**Q. 수집한 전화번호/동의를 나중에 어떻게 쓰나요?**
A. 관리자 화면에서 동의자·연락처 수를 집계로 봅니다. 실제 발송/연락 기능은 별도로 만들면 됩니다(이번 작업 범위 밖).
