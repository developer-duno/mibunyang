# 상세 모달 IA 개편 — Progressive Disclosure (탭 전환 + 요약 대시보드)

> 세션 406 사장님 지시: "상세페이지가 너무 길고 루즈해. 소비자들이 보다가 지칠 것 같아.
> 카테고리를 구분해서 버튼/박스를 클릭해 나가면서 세부내용으로 점점 확대해서 찾아볼 수 있게."
> 경쟁사 벤치마킹 기반 설계 초안 — **구현 진입 시 적대검증 워크플로 1회 의무** (세션 403~406 답습).

## 1. 문제 진단 (실측)

- `DetailModal.tsx` L28-34 `JUMP_SECTIONS` 6개(종합/시세/입지/분양/금융/점수)는 **탭처럼 보이지만 실제론 스크롤 앵커** — 모든 섹션이 한 스크롤에 전부 쌓임 (DetailModal 322줄 + DataSections 307줄 + 차트/표 십수 개 = 모바일 수십 화면 분량)
- **같은 정보 4중 중복**: 카테고리 점수가 ① 종합 레이더 ② 카테고리 박스 6개(도트+서브항목) ③ 점수 섹션 상세 표 ④ 최종 가중 합계 표 — 사장님 스크린샷에서 상품성·입지가 두 번 이상 등장하는 이유
- 깊이 우선순위 없음: 의사결정 핵심(점수·가격·괴리도)과 참고 정보(법률 안내·은행 금리 목록·138필드)가 같은 평면
- 관리자 인사이트(적정가 과정·138필드 표)도 같은 스크롤에 섞임 (adminLoggedIn 시)

## 2. 벤치마킹 (경쟁 서비스 공통 패턴)

| 서비스 | 상세 화면 구조 | 가져올 것 |
|---|---|---|
| **호갱노노** | 첫 화면 = 시세 차트 + 핵심 요약 칩. 나머지는 짧은 카드, 탭하면 깊이. 목록 카드도 3줄 요약→클릭 상세 | "요약 먼저, 깊이는 클릭" — 화면당 1주제 |
| **아실** | 시세/매물/학군/인구 등 **진짜 탭 전환** (콘텐츠 교체 — 스크롤 짧음) | 점프 앵커가 아닌 콘텐츠 교체 탭 |
| **네이버부동산** | 단지정보/시세·실거래가/학군 탭 분리 + 섹션 "더보기" 접힘 | 기본 접힘 + 더보기 |
| **토스** | 요약 카드 → 탭하면 상세 화면 (progressive disclosure 표준) | 미니카드 = 결론 1~2줄 + 진입 버튼 |

공통 원칙: ① 첫 화면 = 의사결정 핵심 5~7개만 ② 깊이는 클릭으로 ③ **한 정보는 한 곳에만**.

## 3. 개선안 (옵션 3 → C 추천)

- **A. 점프 → 진짜 탭 전환만**: JUMP_SECTIONS 6개를 콘텐츠 교체 탭으로. 길이 1/6, 공사 중간. 단 종합 탭이 여전히 길면 미해결.
- **B. 전 섹션 아코디언 기본 접힘**: 공사 최소. 그러나 한 스크롤 유지 + 접힌 제목 수십 개도 루즈함.
- **C. 하이브리드 (추천)** = 탭 전환 + 종합 요약 대시보드:
  - **종합 탭 (기본, 1~1.5화면)**: 점수 도넛+등급 / 핵심지표 6줄(분양가·괴리도·전세가율·미분양률·규제·입주) / **카테고리 미니카드 6개** (점수+결론 1줄, 탭하면 점수 탭 해당 카테고리로) / 시세 미니차트 1개 / CTA(상담·관심·비교·공유)
  - **시세 탭**: 인근 매매/전세 시세 표 + 분양가·미분양 추이 + 층별 매매가 + 네이버 교차검증
  - **입지 탭**: 학군 + 생활인프라 + 교통 상세 + 치안/환경
  - **분양 탭**: 분양정보·일정 + 동/호수 현황 + 청약 경쟁 + 지역 시장 추이 5차트
  - **금융 탭**: 매매/대출 분석 + LTV/DSR 법률 안내(기본 접힘) + 은행별 금리(기본 접힘)
  - **점수 탭**: 카테고리 아코디언 6개 (요약 행 → 펼침 시 서브항목 표) — **현행 4중 중복을 이 한 곳으로 통합** + 최종 가중 합계
  - **관리자 탭** (adminLoggedIn 시에만 노출): 적정가 산출 과정 + 138필드 표 + 평형 표 + 인쇄 — 소비자 화면에서 완전 분리

## 추록 — D1 구현 (세션 407, 적대검증 2라운드 반영)

- **CTA(상담·관심·비교·공유) = 모든 탭에서 항상 노출** (탭 패널 아래 공통 영역, 스크롤러 내부 말미) — 사장님 결정 2026-06-13. §3 옵션 C 의 "종합 탭 CTA" 서술을 대체. CTA 블록 = 모달 마지막 포커서블 불변식(포커스 트랩 경계).
- **"스크롤 위치 초기화" D3 → D1 이동** — 탭 전환 시 이전 탭 스크롤 잔류 방지(top:0 instant 리셋, 가드 밖 setActiveTab).
- **탭별 lazy = 첫 방문 시 마운트 후 keepMounted** (display:none 유지 — 금융 탭 useRef 캐시 훅 refetch·presale_view 중복 발화·펼침 상태 소실 차단). 관리자는 전 패널 즉시 마운트(인쇄 "전체 펼침" 보존, print CSS `[data-tab-panel]` 펼침 규칙 추가).
- **수용 사항**: 소비자 Ctrl+P 인쇄 = 방문 탭만(공식 인쇄 동선은 관리자 전용 — non-goal) / `presale_view` analytics 의미 변화 = "상세 열람"→"분양 탭 첫 열람"(이벤트 볼륨 감소는 정상, 사고 아님) / 분양 탭 미방문 관리자 인쇄물의 lazy 이미지 공백 가능(현행도 유사).
