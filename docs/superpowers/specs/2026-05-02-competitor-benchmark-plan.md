## Context (이 문서는 무엇인가)

세션 161 brainstorming 중 사용자가 분양예정 spec 1차 작성 후 핵심 결정 보강을 요청:

> "이도 한 경쟁사이트를 철저하게 분석해서 벤치마킹 하는 방법밖에없어. 어떤 내용을 담고 있고 우리의 강점을 어떻게 부각시킬건지? 또 사용자가 사용하기 편하게 이런것들을 경쟁사들을 벤치마킹해서 플랜세워줘"

이전까지 표면 조사 6사이트 했으나 깊이 해부는 0. 이 문서는:
1. **5사이트 철저 해부 결과** — 미분양닷컴 / 호갱노노 / 청약홈 / 직방·다방·네이버
2. **차별화 매트릭스** — 7기능 × 6사이트 = 우리만 ◎인 5가지
3. **메시징 전략** — 3중 차별화 카피
4. **흡수할 UX 패턴 5선** — 분양예정 spec + 메인 재설계 spec 양쪽 적용

## § 2. 차별화 매트릭스 — 우리만 ◎인 5가지

| 기능 | 미분양닷컴 | 호갱노노 | 청약홈 | 직방 | 다방 | 네이버 | **★ 우리** |
|------|------------|----------|--------|------|------|--------|-----------|
| 미분양 라벨 정면 노출 | ○ | × | × | △ | × | × | **◎** |
| 41+ 지표 객관 점수 (AHP) | × | △ (17데이터) | × | × | × | △ | **◎** |
| 광고비 영향 0 (객관성) | △ | × | ○ | × | × | △ | **◎** |
| 청약 D-day 알림 | × | ○ | × | ○ | ○ | ○ | **◎ (카카오 알림톡)** |
| 학군·교통·치안·시공사 통합 | × | ○ | × | △ | × | ○ | **◎** |
| 시계열 차트 (분양가/미분양 추이) | × | ○ | × | × | × | × | **◎** |
| "한때 미분양" Success Stories | ◎ | × | × | × | × | × | ◎ (흡수) |

**우리만 ◎인 5가지:** 미분양 정면 노출 + 41지표 객관 점수 + 광고비 0 + 학군교통치안 통합 + 시계열 차트.
**Success Stories 는 미분양닷컴이 ◎이지만 우리도 즉시 흡수 가능 (공개 자료 기반).**

## § 3. 메시징 전략 — 3중 차별화

### 3-1. 메인 카피 (랜딩 헤드라인)

```
지금은 랜드마크인 그 아파트도, 처음엔 미분양이었습니다.
데이터로 검증하세요 — 41개 지표가 좋은 단지를 골라드립니다.
```

**근거:**
- "한때 미분양" 카피 = 미분양닷컴식 (경쟁사 1곳만 사용 중)
- "41개 지표" = 우리만의 객관성 (경쟁사 0)
- "골라드립니다" = AHP 가중치 자동 정렬 (경쟁사 0)

### 3-2. 정체성 박제 카피 (푸터·About)

```
미분양아파트.com 은 단지 점수에 광고비를 일절 반영하지 않습니다.
시행사 자료는 분양 정보 표기 용도로만 노출되며,
점수 산식·정렬 순위는 공공데이터 41+ 지표만으로 결정됩니다.
```

**근거:**
- 미분양닷컴 = 광고 매체 자임 (광고 영향 가능)
- 직방·다방 = 광고비 인상으로 카드 순서 영향 비판
- 호갱노노 = 단지 본문에 중개사 광고 박힘
- 청약홈 = 비-상업이지만 UX 0
- **우리만 "광고비 0" 박제 가능**

### 3-3. 통합 메시지 (분양예정 페이지)

```
지금 청약 받는 단지부터, 곧 분양 시작할 단지까지.
경쟁사가 따로 나눠 보여주는 것을 한 화면에 통합했습니다.
```

**근거:**
- 청약홈 = APT/잔여세대/오피스텔 8개 카테고리 분리
- 호갱노노 = 분양/재건축/경매 분리
- 직방 = 무순위 청약 별도 메뉴
- **우리만 "분양예정 + 청약중 + 분양중 + 추가모집" 한 화면 4단계 배지로 통합**

## § 4. 흡수할 UX 패턴 5선 — 분양예정 spec 보강

### 4-1. 상태 배지 4단계 (직방 변형)

| 단계 | 색 | 의미 | DB 매핑 |
|------|-----|------|---------|
| **분양예정** | 🟢 녹색 | 모집공고 전 | `presaleStage='분양계획'` 37건 |
| **청약중** | 🟡 노랑 | 접수 기간 | `presaleStage='청약중'` 60건 |
| **분양중** | 🔵 파랑 | 청약 후 일반분양 | `presaleStage='분양중'` 295건 |
| **추가모집** | 🔴 빨강 | 잔여세대·무순위 | `unsoldEventCount > 0` (세션 160) |

분양예정 spec § 4-3 의 `<StageBadge>` 컴포넌트에서 4색 매핑.

### 4-2. 4색 종합 점수 분위지도 (호갱노노)

41지표 종합 점수를 구간별 4색으로:

| 점수 구간 | 색 | 의미 |
|-----------|-----|------|
| 8.0+ | 🔵 파랑 | 상위 2% 우수 |
| 6.5~7.9 | 🔴 빨강 | 상위 12% 양호 |
| 5.0~6.4 | 🟡 노랑 | 평균 |
| < 5.0 | ⚪ 회색 | 평균 미만 |

지도 광역 줌 = 시·군·구 4색, 중간 줌 = 단지 핀, 5m 줌 = 41지표 전체.
**메인 재설계(트랙 2) 시 MapView 컴포넌트에 적용.**

### 4-3. 아이콘 그리드 필터 (다방)

현재 `SearchFilterBar` 의 6개 텍스트 FilterButton 을 자주 쓰는 조건은 **아이콘 칩**으로 분리:

```
[🚇 역세권] [🏫 학교] [🆕 신축] [🅿️ 주차] [🏥 병원] [🌳 공원]
```

클릭 시 토글. 메인 재설계(트랙 2) § SearchFilterBar.v2 적용.

### 4-4. 단지 상세 = 탭 분리 (네이버)

현재 DetailModal 200+필드를 6탭으로:

```
[종합] [분양가] [입지] [학군·치안] [시세 추이] [모집공고]
```

각 탭 안에서만 관련 필드 노출. 메인 재설계(트랙 2) § DetailModal.v2 적용.

### 4-5. 편견 깨기 + Success Stories (미분양닷컴)

랜딩 페이지 (트랙 2) 또는 분양예정 페이지 사이드에 섹션:

```
🏆 한때 미분양이었던 랜드마크
- 성수 트리마제 (2017) — 청약 미달 → 현재 평당 1억 돌파
- 둔촌 올림픽파크포레온 (2022) — 무순위 발생 → 현재 입주 임박
- 도곡 타워팰리스 (1999) — 분양 저조 → 강남 랜드마크
```

3사례는 공개 자료 기반 (뉴스 인용 + 이미지 출처 명시).

## § 5. 분양예정 spec 보강 사항 (트랙 1)

기존 `2026-05-02-upcoming-presale-page-design.md` 에 다음 추가:

### 5-1. § 4-2 UpcomingCalendar 색상 범례

청약홈 빈자리 흡수 — 현재 청약홈 캘린더 = 색상 범례 0. 우리는:
- 🟢 분양예정 (녹색 점)
- 🟡 청약 시작 (노랑 점)
- 🟠 청약 마감 (주황 점)
- 🔵 당첨자 발표 (파랑 점)

### 5-2. § 4-3 UpcomingCard "D-day" 강조

청약홈 빈자리 흡수 — 카드 좌측 상단에 큰 글씨:
- `D-7` (청약 1주 전)
- `D-3` (3일 전)
- `오늘 청약` (당일)
- `D+1` (마감 1일 후)

### 5-3. § 4-3 UpcomingCard 용어 풀이 툴팁
