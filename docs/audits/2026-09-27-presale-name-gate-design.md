## 한눈에 (사장님용)

네이버 분양 공고를 우리 단지 행에 붙일 때, 번호가 같은 1순위는 확실하지만 2~4순위(같은 법정동·500m 안·같은 시군구에서 **이름이 비슷한** 단지)는 옆 단지에 잘못 붙어 왔다. 세션578·579가 다른 시군구·ap-* 행·임대/분양 불일치를 막았고, 이번에는 **남은 구멍 = 청약홈 출처(ah-*) 행 + 같은 시군구 + 비슷한 이름**을 막는다.

- **차수·블록이 다르면 거부** — `3BL` ↔ `1BL`, `A6BL` ↔ `A7BL`, `B1블록` ↔ `B2블록` 은 이름이 아무리 비슷해도 다른 단지다.
- **이름이 약하면 거부** — 괄호(`(무순위 1차)`)와 회차 낱말을 뗀 뒤 공백을 지운 두 이름의 유사도가 **0.85 미만이고 한쪽이 다른 쪽에 통째로 들어 있지도 않으면** 다른 단지로 본다(카카오 지도에서 단지를 찾을 때 쓰는 '강함' 기준과 같은 숫자 — 사장님 결정 2026-09-27 01:2x).
- 막힌 공고는 지금처럼 **새 행(새 카드)** 이 된다. 막혀서 보류하면 진짜 새 단지가 영영 안 보이기 때문이다. 대신 로그에 `⚠ 이름 게이트 차단: 공고 → 후보 (이유)` 한 줄을 남겨 월요일에 검토한다.
